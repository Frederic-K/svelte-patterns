# Svelte patterns

Mon carnet de recettes Svelte 5 + SvelteKit + Tailwind v4, en JavaScript.

**Ouvre une fiche, copie les blocs aux endroits indiqués, puis adapte-les à ton projet.** Chaque fiche rassemble le code complet et son mode d’emploi. Ce dossier est de la documentation : rien à installer ni à lancer ici.

## Les recettes

- [Thème clair / sombre](theme.md) — script avant rendu, CSS, bouton, préférence système et synchronisation entre onglets.
- [Navigation](navigation.md) — Header complet, conteneur, couleurs, trait animé et menu mobile.
- [Styles de base et accessibilité](base-styles.md) — Preflight, police, curseur et focus global ou par composant.
- [Retour en haut](retour-en-haut.md) — bouton facultatif, sensible au défilement et au mouvement réduit.

## Mode d’emploi

1. Choisis une recette.
2. Vérifie ses prérequis dans ton projet cible.
3. Crée ou complète les fichiers indiqués au-dessus des blocs de code.
4. Adapte les libellés, couleurs et emplacements à ton besoin.
5. Suis les vérifications à la fin de la fiche.

Les chemins comme src/app.html ou src/lib/components/Header.svelte désignent les fichiers **de ton projet cible**, pas des fichiers présents dans ce carnet. Lorsqu’un fichier existe déjà, ajoute les éléments utiles en gardant ton contenu. Les recettes n’exigent aucune page de démonstration.
